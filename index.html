以 POMDP 三组件（信念维护 → 预测 → 决策）为统一语言梳理具身导航版图。点击节点展开分支并在右侧查看详情；★ 为当前精读中的论文。

0. 问题定义：具身导航是一个 POMDP

POMDP 组件干什么典型实现
信念维护：历史 → 当前世界估计压缩观测历史（记忆）度量地图 / 拓扑图 / 场景图 / 循环隐状态 / 文本档案
预测：状态+动作 → 后果"这么走会怎样"世界模型 / 扩散动作先验 / LLM 常识
决策：估计 → 动作选动作RL 策略 / frontier 打分 / MPC / 大模型推理

目标类型：PointGoal（坐标）→ ImageGoal（图像）→ ObjectGoal（类别）→ VLN（语言指令）→ 需求驱动。指标：SR / SPL / 碰撞 / 时延。

1. 领域树（点击节点展开 / 查看详情）

  • 具身导航 Embodied Navigation
    • A. 按任务目标分
      • PointGoal 点目标坐标目标；DD-PPO 近饱和
      • ObjectNav 物体目标MP3D/HM3D/RoboTHOR；最主流 benchmark
      • ImageNav 图像目标目标=一张照片；实例级外观记忆
      • VLN 语言指令导航R2R/RxR/VLN-CE；"在客厅左转走到沙发"
      • 需求驱动 / 多目标 / 终身Demand-Bench、GOAT-Bench、IVLN
      • 其他：AudioNav · EQA · 社交导航 · 纯探索
    • B. 按系统范式分（主干）
      • 经典管线：SLAM + 几何规划A*/FMM；不作学习，作接口与对照
      • B1. 模块化学习
        • Active Neural SLAM（CVPR'20）显式地图+分层策略的标杆
        • SemEXP / PONI / GOSE语义地图 + 学习探索策略
      • B2. 端到端 RL
        • DD-PPO（PointGoal 天花板）
        • ZSON / THDACLIP 对齐做零样本；采样效率低
      • B3. LLM/VLM 零样本（training-free）
        • B3.1 值图 / frontier 打分
          • CoW（CLIP 梯度查图）
          • VLFM（ICRA'24，值图 frontier）
          • ESC / L3MVN / OpenFMNav / VoroNav / ApexNavLLM 常识给 frontier 打分
        • B3.2 场景图派 ★
          • SG-Nav（NeurIPS'24）在线 3D 场景图 + H-CoT + re-perception
          • UniGoal（CVPR'25）目标也变成图：图匹配统一三类目标
          • GC-VLN（CoRL'25）指令分解为图约束优化
          • 底座：ConceptGraphs / EmbodiedSAM开放词表 3D 实例分割建图
        • B3.3 分层系统
          • InstructNav（值图+地标）
          • SysNav / OmniNav房间级 VLM + 经典执行
        • B3.4 Agentic harness 派（2026 新浪潮）★
          • SuperNav（浙大，2026.10）MLLM 当 agent + Tools/Skills + visual-point 接口
          • HarnessVLN / AgenticNav / Show-Harness
      • B4. 学习派通用策略（真实机器人）★
        • ViNG / ViKiNG（'21/'22）拓扑图+时距估计的奠基
        • GNM（ICRA'23）跨本体通用导航模型
        • ViNT（CoRL'23）Transformer 策略，目标条件导航
        • NoMaD（ICRA'24）goal masking + 扩散动作；单模型统一探索/导航
        • 后继：UniNav / FlowNav世界-动作扩散统一；flow matching 提速
      • B5. 端到端 VLA / 视频大模型
        • NaVid / UniNaVid视频 VLM 直接出动作
        • NaVILA / StreamVLN / Mobility VLA
      • B6. 世界模型导航（预测显式化）
        • Dreamer 系（想象中学策略）
        • NWM（CVPR'25，视频世界模型做规划）
        • NavWM / NavForesee / WMNav
        • SC²-WM / NavMorph带记忆与自校正的导航世界模型
    • C. 按记忆载体分
      • 无显式记忆（纯 reactive）
      • 循环隐状态（RNN/SSM）
      • 度量地图（occupancy/语义俯视）
      • 拓扑图 ★（ViNT/NoMaD）节点=观测图像，边=时距
      • 3D 语义场景图 ★（SG-Nav 系）房间-组-物体+关系边
      • latent/context 记忆（NavMorph CEM 等）
      • 文本/工作区档案 ★（SuperNav）context 工程，无空间对齐
    • D. 按决策接口分
      • 离散动作直接预测
      • frontier 打分 ★（SG-Nav/VLFM）
      • 子目标提议 ★（ViNT/NoMaD 拓扑图搜索）
      • 视觉指点 ★（SuperNav PointNav）
      • WM 想象评估 / MPC（NWM/Dreamer）
    • E. 评测与平台
      • 仿真：Habitat（MP3D/HM3D/OVON）· AI2-THOR/RoboTHOR · Gibson · Habitat-GS
      • 指标：SR / SPL / SoftSPL / 碰撞 / 无效重访 / 时延
      • 真机：LoCoBot · Unitree Go2 · Jackal
