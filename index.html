0. 先定义问题：具身导航是一个 POMDP

具身视觉导航 = 智能体在看不全状态 $s_t$ 的前提下，以第一视角视觉（RGB/RGB-D）为主要观测 $o_t$，选择动作序列 $a_t$ 到达目标 $g$。它是部分可观测马尔可夫决策过程（POMDP）："看不全、要记住、想清楚再走"的序贯决策问题。

POMDP 组件干什么本领域的典型实现
信念维护：历史 $H_t$ → $\hat{s}_t$把观测历史压缩成对世界的当前估计（记忆）度量地图 / 拓扑图 / 场景图 / 循环隐状态 / 文本档案
预测：$(\hat{s}_t, a)$ → 后果回答"这么走会怎样"可学习世界模型 / 扩散动作先验 / LLM 常识（伪预测）
决策：$\hat{s}_t$ → $a$在信念上选动作RL 策略 / frontier 打分 / MPC 想象 / 大模型推理

目标类型决定"什么信息相关"：PointGoal（坐标）→ ImageGoal（图像）→ ObjectGoal（类别）→ VLN（语言指令）→ 需求驱动（"找个能休息的地方"）。评测四前提必须声明：行动接口、观测权限、计算预算、环境动态性。指标：SR / SPL / SoftSPL / 碰撞 / 时延（常被漏报）。

1. 领域树（点击展开）

  • 具身导航 Embodied Navigation
    • A. 按任务目标分
      • PointGoal 点目标 — DD-PPO（2.5B 帧近乎饱和）；几何与连通性记忆的最低配置
      • ObjectNav 物体目标 — MP3D / HM3D / RoboTHOR / HM3D-OVON；评测口径批判见 ObjectNav Revisited
      • ImageNav 图像目标 — 实例级外观+空间关系记忆；ViNT/NoMaD 的主战场
      • VLN 语言指令 — R2R / RxR / VLN-CE；GC-VLN ★、NavMorph、SC²-WM 所在
      • 需求驱动 / 多目标 / 终身 — Demand-Bench（"准备 workspace"）、GOAT-Bench（连续多目标）、IVLN（tour）；SuperNav ★ 的差异化战场
      • 其他：AudioNav · EQA · 社交导航 · 纯探索（coverage）
    • B. 按系统范式分（主干）
      • 经典管线 — SLAM + 几何规划（A*/FMM）；不作学习，作接口与对照
      • 模块化学习
        • Active Neural SLAM（显式地图+分层策略）、SemEXP、PONI、GOSE —— 语义地图 + 学习探索策略
      • 端到端 RL
        • DD-PPO、ZSON（CLIP 对齐零样本）、THDA —— 采样效率低、类别受限
      • LLM/VLM 零样本（training-free）— 清华线所在
        • 值图 / frontier 打分：CoW、VLFM、ESC、L3MVN、OpenFMNav、VoroNav、ApexNav
        • 场景图派：SG-Nav（NeurIPS'24）→ UniGoal（CVPR'25）→ GC-VLN（CoRL'25）关注
          在线 3D 层次场景图（房间-组-物体）+ LLM 分层 CoT 推理 + re-perception 校正；主线=图表示不变、不断拓宽目标类型
        • 分层系统：InstructNav（值图）、SysNav（房间级 VLM+经典算法）、OmniNav（快慢系统）
        • Agentic harness 派：SuperNav（浙大 2026.10）· HarnessVLN · AgenticNav关注
          MLLM 当自主 agent + Tools/Skills/context 工程；visual-point 接口；无持久空间记忆
      • 学习派通用策略（真实机器人行为克隆）— Berkeley 线所在
        • ViNG → ViKiNG → GNM → ViNT（CoRL'23）→ NoMaD（ICRA'24）关注
          Transformer 策略 + 扩散动作解码 + goal masking 统一探索/导航；拓扑图 episodic memory 做长程
        • 后继：UniNav（世界-动作扩散统一）、FlowNav（flow matching 提速）等
      • 端到端 VLA / 视频大模型
        • NaVid、UniNaVid、NaVILA、StreamVLN、Mobility VLA —— 视频/指令直接出动作，通用但黑箱、数据饥渴
      • 世界模型导航（预测显式化）
        • Dreamer 系（想象中学策略）、NWM（视频世界模型做规划/候选排序）、NavWM、NavForesee（预测特征而非像素）、WMNav、SC²-WM（自校正）、NavMorph（上下文记忆）——综述的核心层
    • C. 按记忆载体分（综述核心维度）
      • 无显式记忆（纯 reactive 策略）
      • 循环隐状态：RNN/SSM（R2I；属基座状态，不算档案 M）
      • 度量地图：occupancy / 语义俯视地图（ANS、SemEXP）
      • 拓扑图：节点=观测图像、边=时距（ViNT/NoMaD）C10
      • 3D 语义场景图：房间-组-物体+关系边（SG-Nav/UniGoal/GC-VLN；ConceptGraphs、Khronos）C11
      • latent/context 记忆：NavMorph CEM、SC²-WM VCM
      • 文本/工作区档案（context 工程型）：SuperNavC10，无空间对齐
    • D. 按决策接口分
      • 离散动作直接预测（RL、NaVid 系）
      • frontier 打分（VLFM、SG-Nav ★）
      • 子目标提议（ViNT subgoal diffusion、拓扑图搜索 NoMaD ★）
      • 视觉指点 PointNav（SuperNav ★）
      • WM 想象评估 / MPC（NWM、Dreamer）
    • E. 评测与平台
      • 仿真：Habitat（MP3D/HM3D/HM3D-OVON）、AI2-THOR/RoboTHOR、Gibson、Habitat-GS/InteriorGS、Isaac
      • 指标：SR / SPL / SoftSPL / 碰撞 / 无效重访；时延与调用成本普遍漏报（我们综述的靶点）
      • 真机：LoCoBot（NoMaD）、Unitree Go2（SuperNav、我们的复现平台候选）

2. 当前关注点：深读笔记

2.1 SG-Nav 系（清华 · Hang Yin / Jiwen Lu）

SG-Nav（NeurIPS 2024）C11M1 场景图F1 re-perception

做什么：在线构建"房间-组-物体"三层 3D 场景图代替纯文本 prompt；H-CoT 四步让 LLM 沿子图推理目标位置；frontier 得分 = Σ P_sub/D 距离加权插值；re-perception 累积可信度纠正误检（N_max=10, S_thres=0.8）。

关键数字：MP3D SR 40.2（首个超有监督的零样本方法）；消融：去场景图 −10.8 SR、去 re-perception −3.6 SR；LLaMA-7B ≈ GPT-4（方法不依赖强模型）。

学习要点：① 增量建边的批量 prompt 把复杂度从 O(m(m+n)) 降到 O(m)；② 短边用 VLM 验证 LLM 假设、长边用几何判据——"内部预测不当独立测量"的范本；③ 局限：依赖在线 3D 实例分割、只做 ObjectNav、不报时延。

UniGoal（CVPR 2025）· GC-VLN（CoRL 2025）

UniGoal：统一物体/图像/文本三类目标为图匹配问题（目标也变成图），多阶段探索（全匹配→部分匹配）。GC-VLN：VLN 指令分解为图约束优化，training-free。主线读法：场景图表示不变，目标类型不断拓宽——下一环自然是接入可学习预测器（世界模型）。

2.2 NoMaD 系（Berkeley · Dhruv Shah / Sergey Levine）

ViNT → NoMaD（CoRL 2023 → ICRA 2024）C10M1 拓扑图F0 无校正

做什么：ViNT = EfficientNet-B0 编码过去 5 帧 + goal 融合 token → 4 层 Transformer → 双头（未来 8 waypoint + 时距），100+ 小时真实数据行为克隆。NoMaD = ViNT + 两个改动：① goal masking（attention 屏蔽 goal token，p=0.5 训练，单模型统一探索/导航）；② 扩散动作解码（1D U-Net，10 步去噪，建模多峰无碰撞动作分布）。

关键数字：探索 98% 成功/0.2 碰撞，超 ViNT subgoal-diffusion 25%+，参数 19M（小 15×），跑 Jetson Orin。

学习要点：① 拓扑图=episodic memory，边由时距 head 估计，图搜索给长程子目标；② 扩散生成的是动作不是图像；③ 局限：目标只能是图像、无语义、拓扑图只增不纠（无失效机制）、笨 frontier 无 semantic prior。

2.3 SuperNav（浙大 3DV 组，2026.10）

Agentic harness + MLLMC10M1 文本档案F0 提示级复查

做什么：GPT-5.6 级 MLLM 当自主 agent；Tools（四向观测/PointNav 指点/进度/终止）+ Skills（Markdown 说明书）+ context 剪枝；双后端可换（Geo：深度+navmesh+A*；Learned：NoMaD 启发的 flow 策略——两条主线系统级合流的证据）。

关键数字：实例导航 78%（UniNaVid 34%）、需求驱动 59.5%、HM3D-OVON 73.3%@1m + Go2 真机。

学习要点：任务通用性靠 agent 解释力而非工作流改造；软肋=无持久空间记忆（重访靠视觉识别）、成本/时延自认不可控、完成判断是 MLLM 自报。

4. 两周真机复现计划（SG-Nav → NoMaD）

目标：找出仿真论文里看不到的真实问题
产出：通俗 Word 报告（给导师）
平台候选：Unitree Go2 / 现有移动底盘

Week 1：SG-Nav（清华线）

复现要点：官方代码 github.com/bagh2178/SG-Nav；感知栈（开放词表检测+实例分割合并）→ 场景图增量构建 → LLM H-CoT 打分 → FMM 局部规划。真机适配的关键替换：RGB-D 来源（RealSense/Go2 相机）、位姿来源（里程计/SLAM）、LLM 端点（GPT API 或本地 LLaMA）。

要记录的真实问题：① 每步 LLM 调用次数与 wall-clock（论文不报，我们测）；② 开放词表检测在真实光照/杂物下的误检率，以及 re-perception 能救回多少；③ 场景图规模随时间的膨胀与剪枝有效性；④ 离散动作假设（0.25m/30°）在真实走廊的别扭程度。

Week 2：NoMaD（Berkeley 线）

复现要点：官方代码 github.com/robodhruv/visualnav-transformer（GNM/ViNT/NoMaD 同库）；预训练 checkpoint 直接可用；部署=拓扑图在线构建 + 扩散策略推理（Jetson 可跑）。

要记录的真实问题：① 目标图像采样方式对成功率的影响（image-goal 的天然歧义）；② 探索模式在多岔口环境的覆盖率 vs frontier 语义先验的缺失；③ 动态障碍（行人）下扩散多峰分布的反应；④ 与 SG-Nav 同场景对照：一个"会走但不理解"，一个"理解但慢"。
